# Interface

Visual thesis: a quiet local utility, ivory surfaces, dark type and one green accent.
Content: account status, local API address, key list; separate key details and short creation/test dialogs.
Interactions: subtle action feedback and dialog transitions, respecting reduced motion.

The vector logo uses opposing code brackets and a central connector, with a green activity point. It is shared by the app header, favicon and repository README. No external font or asset request is required.

English is the default; a persistent English/French selector lives in the header. The browser is only the management UI. Programs use the local HTTP service.
