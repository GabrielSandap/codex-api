If a request fails
Connection refused
Check that Codex API is running and that the address and port are correct.
401 error
The key is missing, incorrect, expired or revoked.
400 error
Check the request fields. This preview supports text only, without streaming or tools.
429 error
The service is limiting the request rate or concurrency. Wait before retrying.
502 error
Read the returned message and check your Codex account connection and limits.
